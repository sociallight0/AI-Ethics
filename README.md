# AI Ethics: Designing Responsible and Fair AI Systems

## Overview

This repository contains the implementation and documentation for the *AI Ethics* assignment from the *AI for Software Engineering* course at PLP Academy. The project focuses on designing responsible and fair AI systems by analyzing ethical principles, auditing AI models for bias, and proposing solutions to real-world ethical dilemmas. The assignment is divided into:

1. **Case Study Analyses**: Evaluating ethical issues in AI scenarios (e.g., COMPAS recidivism prediction) and proposing mitigation strategies.
2. **Technical Audit**: Using AI Fairness 360 to audit the COMPAS dataset for biases, with fairness metrics like disparate impact ratio and equal opportunity difference.
3. **Reflections**: Critical reflections on AI ethics principles (e.g., transparency, accountability) and their societal impact.

A bonus task article is also shared in the PLP Academy Community.
